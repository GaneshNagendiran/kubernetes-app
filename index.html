Project Overview

This project demonstrates how a web application can be containerized with Docker, stored in Amazon ECR and prepared for deployment on a Kubernetes cluster running on Amazon EKS.

G

GitHub

Stores the application source code and provides version control for the DevOps workflow.

D

Docker

Packages the application and Nginx web server into a portable container image.

E

Amazon ECR

Provides a private container registry for storing and managing the Docker image.

K

Kubernetes

Provides container orchestration and manages application workloads using Pods and Services.

E

Amazon EKS

Provides a managed Kubernetes control plane for running containerized workloads on AWS.

N

Nginx

Serves the HTML application from inside the Docker container.

Deployment Workflow

The application follows a complete DevOps workflow from source code to cloud-based container orchestration.

01

Source Code

Application source code is maintained in a GitHub repository.

02

EC2 Instance

The project is cloned and verified on an Amazon Linux EC2 instance.

03

Docker Build

The Dockerfile is used to build the application container image.

04

Local Testing

The Docker container is started and tested locally on the EC2 instance.

05

Amazon ECR

The Docker image is tagged and pushed to the private ECR repository.

06

EKS Cluster

An Amazon EKS Kubernetes cluster is created using eksctl.

07

Worker Node

A managed node group provides a worker node for running Kubernetes workloads.

08

Kubernetes

kubectl is configured and the cluster health is verified using Kubernetes commands.
