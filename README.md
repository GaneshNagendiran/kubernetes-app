# Kubernetes Docker ECR EKS Application

## Project Overview

This project demonstrates the deployment of a simple web application using:

- GitHub
- Amazon Linux EC2
- Docker
- Amazon ECR
- Kubernetes
- Amazon EKS
- Nginx
